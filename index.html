Deploy to GitHub Pages
  1. Click Download HTML and save as index.html
  2. Create a new GitHub repo (example: my-profile)
  3. Upload index.html to the root of the repo
  4. Go to Settings then Pages, set source to main branch
  5. Your profile is live at yourusername.github.io/my-profile
  6. For a custom domain, add it in Settings then Pages then Custom domain
